## O que é

Um único aplicativo com TODAS as ferramentas que faltavam no seu Android:

| Aba | Função | Status |
|-----|--------|--------|
| ⚡ **Boost** | Modo Jogo: mata background, limpa caches, libera RAM | ✅ |
| 🎭 **Troll** | Notificações fake customizadas ("telefone vai explodir") | ✅ |
| 📊 **Aparelho** | Ficha completa do hardware e sistema | ✅ |
| 🧹 **Limpeza** | Cache global + desativador de bloat | 🚧 |
| ⚙️ **CPU** | Governador, frequências, cores online/offline | 🚧 |
| 🎭 **Spoof** | Trocar modelo/marca do aparelho (resetprop) | 🚧 |

## Requisitos

- Android 10+ (API 29)
- Root via Magisk para as funções avançadas
- Companheiro ideal do [LSPosed ET](https://github.com/EzequielDevTeam/LSPosed-ET)

## Build

```bash
./gradlew :app:assembleDebug
```
